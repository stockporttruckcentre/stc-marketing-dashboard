# Source documents

Documents received from the business, stored exactly as they arrived.

Nothing in this folder is edited, reformatted or tidied. These are the record of
what was asked for, and a spec you have quietly rewritten is no longer evidence
of anything. If a line here is wrong, the correction goes in the build docs that
cite it, not in the file itself.

**This folder is the one exception to the em dash ban in `CLAUDE.md`.** The rule
governs prose written for this repository. It does not govern a document somebody
else wrote and handed over. `crm-page-scope.md` contains 137 of them and they
stay there.

| File | What it is |
|---|---|
| `crm-page-scope.md` | Per page CRM build spec derived from the Tom, Dave and Alex meeting. Covers every tab, with provenance on each item. Excludes the Dashboard and News, which were specced separately |

Where a source document drives current work, the build doc that implements it
says so and tracks what is done against it. For `crm-page-scope.md` that is
`docs/crm-scope-compliance.md`.
