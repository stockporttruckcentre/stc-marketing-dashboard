Principles

The rules that keep it from drifting back to generic.
01 Navy acts, red points Navy carries primary actions and structure. Red is reserved for the one thing that matters on a screen, and for destructive intent. A screen with three red buttons has none.
02 Density is a feature Built for tools people work in all day: tables, schedules, long lists. 32px controls, 36px rows, 14px base text. Whitespace goes between groups, not inside them.
03 Borders before shadows Structure comes from 1px rules and honest alignment. Elevation is for things that genuinely float: menus, dialogs, popovers, drag states.
04 Panton earns its size Panton is for headings, numbers and labels that need authority. Everything a user reads at length is Inter. Never set Panton below 11px.
