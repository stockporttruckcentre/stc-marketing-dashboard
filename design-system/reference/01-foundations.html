Typography

Panton for authority, Inter for everything read at length. Base is 14px.
DISPLAY AND HEADINGS Panton ExtraBold Panton Bold, 700 Tracking tightens as size grows: -0.04em at display, -0.03em at heading, -0.02em at 18px and below. Never set Panton below 11px, and never for running text.
INTERFACE AND BODY Inter SemiBold, 600 Inter Regular carries every label, value, paragraph and table cell. Numbers in tables and metrics use tabular figures so columns align. 1234567890 · tabular-nums

Radius and border

4px is the default everywhere. Softened, not rounded.
sm · 2pxTags, swatches, tiny chips
base · 4pxButtons, inputs, badges, menu items
md · 6pxCards, panels, popovers
lg · 8pxDialogs, drawers, sheets
fullAvatars, status dots, toggles only
1px · borderThe default. Card edges, table rules, dividers.
1px · border-strongInput outlines and anything interactive at rest.
2px · border-emphasisSection rules under headings, active tab underline.

Elevation

Navy tinted in light, black in dark. Four levels, and most screens use one.
shadow-1Cards at rest, resting rows
shadow-2Hovered cards, sticky headers
shadow-3Menus, popovers, dropdowns
shadow-4Dialogs, drawers, dragged items
Rule. In light mode shadow carries elevation. In dark mode a black shadow on a navy field does almost nothing, so elevation is carried by surface tint instead: each layer steps one rung up the navy scale. Keep the shadow token on as well, and always give a floating surface a hairline so its edge reads on any background.
SURFACE LADDER
--surface-sunkenWells, code blocks, disabled fills
--bgThe page canvas
--surfaceCards, panels, inputs, menus
--surface-raisedDialogs and popovers, one step above

Motion and focus

Fast enough to feel mechanical, never decorative.
DURATIONS
120msHover, colour, border
160msPopovers, tooltips, menus
220msDialogs, drawers, panel slides
cubic-bezier(0.2, 0, 0, 1)The only curve
FOCUS RING
2px solid --focus at 2px offset, on every interactive element. Navy-500 in light, navy-300 in dark. Deliberately not red, so focus is never mistaken for an error.
