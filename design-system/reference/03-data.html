Empty states

What a brand new account sees. Every list needs one, and it is never the words "No data".
Three kinds
No assets yetAdd the first vehicle or trailer and its inspection schedule builds automatically.
Nothing matches those filtersTwo filters are active. Clearing the site filter would return 41 records.
Could not load accountsThe request timed out. Nothing has been lost.
Skeletons
Skeletons match the shape of what is loading. If you cannot match the shape, use a spinner instead.
An empty state always says what the thing is, why it is empty, and the single action that fills it. A screen that says only "No results" has wasted the one moment the user was paying attention.
