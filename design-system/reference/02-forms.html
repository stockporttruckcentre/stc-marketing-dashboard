Forms and inputs

Every control a user types into, picks from or toggles. Each one is shown across its full state matrix: rest, hover, focus, disabled, loading and invalid, in both themes.

Button

Seven variants. Navy is the default action, red is reserved for the single most important action on a screen and for destructive intent.
Variants
Never place two accent buttons in the same view. If both matter, one becomes secondary.
Sizes
Medium (32px) is the default. Small for table row actions and toolbars, large for a single primary call to action.
